# 文章来源标记

主题分类 `category`（例如人工智能、生活思考）与文章来源 `sourceType` 相互独立。来源显示在首页文章行、全部文章页与阅读页；全部文章页可按来源筛选。

在 `public/article-data/index.json` 的文章条目中添加：

```json
"sourceType": "original"
```

| 值 | 显示 | 适用情况 |
| --- | --- | --- |
| `original` | 原创 | 自己撰写或主导创作的文章，包括与 AI 协作写作 |
| `repost` | 转载 | 转载他人已有文章；按授权要求在正文保留作者与来源说明 |
| `ai-research` | AI 共研 | 与 AI 围绕问题共同研究、整理形成的报告或结论，而非转载已有文章 |

原创文章若需要说明 AI 协作，可另加 `"aiAssisted": true`，阅读页会显示“与 AI 协作完成”。这不自动将文章归入 AI 共研。

未填写或无效的 `sourceType` 不显示来源标记，仍会出现在“全部”里；不会自动认定为原创。旧文章应逐篇确认后补充来源。格式为 Markdown 或 HTML 不影响来源分类。

“原创／转载／AI 共研”是本站的内容来源说明，不代替发布前的事实核查或授权判断。
